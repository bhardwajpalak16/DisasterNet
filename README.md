# DisasterNet

> **Stay Safe. Stay Connected.**
>
> An offline-first disaster management and emergency communication platform designed to help communities stay informed, connected, and prepared during emergencies.

## 🚨 Overview

DisasterNet is a disaster-management platform focused on providing essential emergency information, communication, alerts, and survival resources through a simple and accessible interface.

The platform is designed with an **offline-first approach** so that important information remains accessible even when internet connectivity is limited or unavailable.

## ✨ Features

- 🚨 Emergency Alerts
- 🆘 SOS / Emergency Assistance
- 📍 Offline Disaster Map
- 🤖 AI Emergency Assistant
- 📢 Community Emergency Alerts
- 🪪 Medical ID & Emergency Information
- 📡 Offline Communication Support
- 🧭 Survival & Disaster Guides
- 🔔 Emergency Beacon
- 👤 User Profile & Settings
- 📱 Responsive User Interface
